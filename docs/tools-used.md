# 개발 도구 검토와 실제 사용 상태

2026-10-02 플러그인 검색과 호출 결과를 기준으로 정리했습니다. 설치됨, 계정 연결됨, 실제 사용함은 서로 다릅니다.

| 도구               | 확인된 상태                             | 이번 작업에서 한 일                                                                |
| ------------------ | --------------------------------------- | ---------------------------------------------------------------------------------- |
| Figma 플러그인     | 설치됨 · 계정 연결 안 됨                | 구조도 생성 호출을 시도했으나 로그인·연결이 없어 생성되지 않음                     |
| Canva 플러그인     | 검색 결과 설치됨 · 연결은 검증하지 않음 | 이번 구현에서 사용하지 않음                                                        |
| Superpowers | 설치됨 · 6.4.2 | 최종 검증·독립 리뷰 완료. 추가 표시 오류를 실제 브라우저에서 재현하고 수정 후 확인 |
| MagicPath          | 미설치                                  | UI 제작 후보로 검토, 사용하지 않음                                                 |
| Codex Security     | 미설치                                  | 보안 검토 후보로 검토, 사용하지 않음                                               |
| 브라우저 제어 기능 | 실제 사용                               | 장애 접수·점검·가이드 저장, 데스크톱·모바일 화면, 키보드 동작과 실제 스크린샷 확인 |

Figma 연결이 없어 구조도는 로컬 SVG로 제작했습니다. 화면은 React와 자체 CSS, 아이콘은 lucide-react를 사용했습니다. 회사 로고·유료 템플릿·가상 실적 이미지를 가져오지 않았습니다.

사용자가 지정한 6-1-sol-orch 흐름으로 공개자료 조사, 백엔드 구현, 통합 검증을 나누었습니다. 백엔드는 GPT-6.1 Sol 작업자, 최종 데이터 정합성·보안 검토는 GPT-6 Astra 검토자가 수행했습니다. 검토에서 발견된 과거 실패 원인 선택 문제를 수정하고 회귀 테스트를 추가했습니다. 최종 UI·README·실행 점검은 통합 작업에서 완료했습니다.

초기에는 설치 후보로 제안했고, 이후 사용자가 설치한 Superpowers 6.4.2를 확인했습니다. 설치 후 using-superpowers, verification-before-completion, requesting-code-review와 systematic-debugging 절차를 적용했습니다. 독립 리뷰에서 찾은 최근 실패 개수 표시 오류를 브라우저에서 재현하고 수정 후 같은 기록으로 확인했습니다. 최종 npm run check는 타입 검사·자동 테스트 10/10·빌드 모두 통과했습니다. 이 플러그인은 개발 절차를 돕는 도구이며, 점검실 실행의 필수 의존성은 아닙니다.

대표 시연 개선에서는 GPT-6.1 Sol 작업자가 DemoJourney 화면과 CSS를 맡고, 통합 작업에서 기존 API 연결·README·실제 실행 검증을 진행했습니다. GPT-6 Astra 독립 리뷰에서 부분 실패 후 낡은 정상 표시가 남는 문제를 찾아 수정했습니다. 로컬 검증용 HTTP 프록시로 실제 POST /runs 실패를 발생시켜 표시와 가이드 저장 조건을 확인했습니다.
